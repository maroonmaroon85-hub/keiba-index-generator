# 環境構築チェックリスト（90-env-setup）

**これはClaude Codeのタスクではなく人間側の作業。** Phase 1の開発と並行して進められる。

Apple Silicon Mac前提。

## 手順
1. [ ] VMware Fusion Pro（個人利用無償）をインストール
2. [ ] Windows 11 ARM をVMとしてインストール
   - x64エミュレーション内蔵なのでJV-Link/TARGET（Intel向けアプリ）が動く
   - ディスクは60GB以上割り当て（TARGET初回セットアップのデータ量対策）
   - Windowsライセンスは未認証でも機能制限つきで動作する
3. [ ] **Windows側のブラウザで** JRA-VANにログインし、DataLab利用キーを取得
4. [ ] JV-Linkをインストールし、JV-Link設定アプリ（Windows検索で「JV-Link」）で利用キーを登録
5. [ ] TARGET frontierJVをインストールし、初回データセットアップを実行
   - 数時間かかることがある。**Macのスリープで処理が止まる**のでスリープ無効化して放置
6. [ ] VMware共有フォルダで `~/keiba-data` をWindows側にマウントし、TARGETのCSV出力先に指定

## ⚠️ よくあるつまずき
- JV-Link・TARGET・JRA-VANログインは**すべてWindows側**で行う。Mac側のブラウザ/インストーラーで始めると最初から詰まる
- 利用キーはTARGETではなくJV-Link設定アプリに入れる

## ⚠️ リスクとフォールバック
- Windows 11 ARM＋x64エミュレーションでのJV-Link/TARGET動作は実例報告ベースで、公式保証はない。**手順3〜5（利用キー登録〜初回セットアップ）を最優先で検証**し、動かない場合はWindows VPS（月500〜1,000円程度）にJV-Link/TARGETを置く構成へ切り替える。生成層（Mac側）の設計は変わらないので開発への影響はCSVの受け渡し方法のみ

## 無料期間（確定情報）
- DataLabの無料期間はJV-Linkインストール日起算で1ヶ月。終了後は月額2,090円（税込）
- **今回の起算日: 2026/07/04（インストール済み）→ 期限目安: 2026/08/03頃**
- この1ヶ月でやり切ること（優先順）:
  1. VM上でTARGET初回セットアップまで動作検証（動かなければVPSへ切替判断）
  2. 過去レースデータ（成績・払戻含む）を**取れるだけ一括CSV出力**（目安: 5〜10年分）→ Phase 3バックテスト用＋将来の機械学習モデル（Phase 5構想）の学習データ。期間終了後も検証・学習を続けられる資産になる
  3. 週末レースでPhase 1-2のパイプラインを実データ稼働
- 継続課金するかは、期限までにバックテストの回収率を見て判断する
