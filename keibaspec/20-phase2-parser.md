# Phase 2: TARGET実CSVの接続（20-phase2-parser）

前提: Phase 1完了、かつユーザーからTARGET frontierJVで実際にエクスポートしたサンプルCSV（1レース分）を受領していること。**受領前に想像でparserを書かない。**

## ゴール
TARGETのCSV出力を読み込み、Phase 1の内部モデル（PreRaceData）に変換して既存パイプラインに接続する。

## 最初に確認すること（実装より先）
1. ファイル構成: CSVが何ファイルに分かれているか（出馬表/過去成績/調教など）。TARGETの出力は機能ごとに分かれており、1枚に全て入るとは限らない
2. **結合キー**: 血統登録番号が含まれるか。なければ馬名＋生年月日等の代替キーを決め、ユーザーに確認する
3. エンコーディング（Shift_JISの可能性が高い。iconv-liteで変換）と区切り文字
4. 不足カラム: 内部モデルに対して足りない項目を洗い出し、TARGET側の出力設定で追加可能かユーザーに確認する

## タスク
1. 上記の確認結果を `data/sample/schema.md` に記録（カラム対応表: CSV列名 → 内部モデルのフィールド）
2. parser実装: 複数CSV読み込み → キーで結合 → PreRaceData構築 の3段構成
3. 実CSVでHTML/JSONを生成し、ダミーデータ時と同等の出力になることを確認
4. パース失敗・欠損データ時のエラーメッセージをわかりやすく（どのファイルの何行目か）

## 完了条件
- 実CSV 1レース分からHTMLとJSONが生成できる
- schema.md にカラム対応表が揃っている
- ここで停止してレビューを受ける
